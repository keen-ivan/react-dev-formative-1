# Reflection

This project helped me better understand how React applications are structured using reusable components. I gained more practical experience with component composition by connecting the `Header`, `PostList`, `Post`, and `App` components. Working with TypeScript was also useful because defining the `PostData` interface and component props helped me understand how type safety can make React code easier to maintain.

I also found the optimization and Higher-Order Component requirements useful because they introduced concepts beyond basic UI development. Using `React.memo` helped me understand how unnecessary re-renders can be reduced, while creating the `withLogger` HOC helped me understand how additional behavior can be added to existing components. Through this project, I also became more comfortable with conditional rendering, reusable components, styling, and organizing a React project into separate files.

In future React projects, I would like to explore state management, routing, and connecting applications to real APIs.
